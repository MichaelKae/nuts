# ♠ Nuts

Покерный таймер для домашних игр: блайнды, докупы, кэш и турниры, расчёт «кто кому переводит», хронология вечера.
Работает в браузере на ноутбуке, телефоне, планшете и ТВ.

**Открыть:** https://michaelkae.github.io/nuts/

## Возможности

- **Таймер**: уровни и перерывы, звук и озвучка блайндов, режим ТВ, подгонка под любой экран
- **Игроки**: вылеты, докупы с лимитами, аддоны, поздняя регистрация, случайная рассадка, баунти
- **Кэш**: курс денег к фишкам, подсчёт фишек в конце, расчёт переводов минимальным числом платежей
- **Турнир**: призовой фонд, выплаты по местам (авто по числу игроков)
- **Фишки**: несколько наборов, калькулятор стартового стека, подсказки, когда убирать мелочь
- **Структура**: генератор от гипертурбо до слоуролла, плавающая длина уровней
- **История**: хронология каждого вечера, архив игр, отчёт в чат одной кнопкой
- **Хранение**: автоматически в браузере, плюс файл на диске и резервные копии

## Запуск

Открыть ссылку выше или скачать `index.html` и открыть в браузере — ничего устанавливать не нужно, работает офлайн.
